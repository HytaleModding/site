<Question title="Are there any plans to improve Asset Loading or overriding other assets?" askedBy="riprod">
  <Answer person="kaupenjoe">
    The note I have on that is, as they are sort of almost every major system, they’re also reworking the asset system, and I hope that something like that would come in there, but that’s as much detail as I have on that one.  On overriding assets, it works to some degree, but only with very specific things.  
  </Answer>

  <Answer person="zeroerrors">
    So basically the way that it works is that when you have a parent field that is set to “super”, it will automatically have the parent object of that asset use whatever is already loaded in the assets. So, for example if you have multiple packs and they load in a specific order, so you have the base game with a certain item, and you have your pack that gets loaded later, and it has the parent set to super, the pre-existing one that was loaded by the base-game will be the object that is the parent, and the child one when it loads will use that to do inheritance, and what happens is as it goes through and loads the fields in the CODEC, if the field is added with the inherited method, they have a 3rd argument that allows it to take a value from the parent object and add it to the current one. That’s how the parenting system works.
  </Answer>
</Question>

<Question title="What kind of testing tools or libraries are currently used in the development of Hytale?" askedBy="haro0">
  <Answer person="zeroerrors">
    A lot of the stuff we have is in-house. At the base level, it’s just C# and Java. We have some tools that we built for automated testing, and we do have the usual testing frameworks as well. I mentioned in the Discord at one point that we also have a build tool that helps build the game. That has a test framework built into it that boots up the client and a server and tests some scenarios to make sure things are the way they are supposed to be. It’s pretty limited right now, but we want to make sure that when we pick up problems, we can regression test and avoid them coming up again in the future.
  </Answer>
</Question>

<Question title="The Instances system currently is not the best. Do you think there would be improvements that you want to do to that? Follow-up to that, will there ever be a feature where you can add multiple entry and exit points to Instances?" askedBy="quentin_qptech">
  <Answer person="zeroerrors">
    There are multiple levels here. At the base level, you have the server itself, which supports multiple worlds. On top of that, you have instances, which allow you to have an asset that defines a world with either a savegame, a pre-made world, or a configuration for world generation. On top of that, there are the actual instances in the game, which you see with the portals. It depends on what level you’re talking about. On the gameplay side, there will always be iteration to make sure the game is fun and enjoyable, but on the lower-level systems, if there is feedback on how instances themselves or worlds within the server actually function, we would love to hear it.
  </Answer>
</Question>

<Question title="Is it possible or planned to be able to add new phobia modes?" askedBy="edilan">
