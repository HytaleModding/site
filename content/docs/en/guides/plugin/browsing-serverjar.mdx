Hytale has released the code for the Hytale Server under the [Hytale Shared Source License Agreement](https://hytale.com/shared-source-license). This means that you can browse the source code for the Hytale Server directly on GitHub without needing to download and decompile the server yourself. 

Please visit https://accounts.hytale.com/shared-source to access the Hytale Server source code on GitHub. You must have a Hytale account with an active Game license to access the source code. 

<Callout type="info">
This guide was written originally to decompile the server jar, but now that the source code is available, we have removed the decompilation instructions and replaced them with instructions for browsing the source code on GitHub.
</Callout>
