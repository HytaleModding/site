Bem-vindo(a) à documentação de criação de mods para o Hytale. Esta seção contém o guia completo para o desenvolvimento dos seus próprios mods para o Hytale.

## Por onde começar

Se você não sabe nada sobre criar mods para Hytale ou até mesmo sobre Java, ou se quer revisar seus conhecimentos, aqui estão alguns links que podem te ajudar.

* [Fundamentos do Java](./guides/java-basics/00-introduction) — Aprender a sintaxe e os recursos de linguagem que você precisará para criar mods;
* [Aprendendo a aprender](./guides/learning-to-learn) — O motivo de usarmos Java;
* [Configurando seu ambiente de desenvolvimento](./guides/plugin/setting-up-env) — Configure seu projeto de desenvolvimento;
* [Build and test](.guide/plugin/build-and-test) - build your project.
* [Logging](./guides/plugin/logging) - find and interpret output from your mod when you run the game.
* [Creating a Block](./guides/plugin/creating-block) - build a simple block to verify your setup works.

Se você tem experiência ou deseja tentar algo mais difícil:

* [World Generation](./guides/plugin/world-gen) - add new terrain, biomes, and custom ore spawns.
* [Custom Camera Controls](./guides/plugin/customizing-camera-controls) - change how the player camera behaves during gameplay.
* [Entity Component System (ECS)](./guides/ecs/entity-component-system) - how to use ECS.
* [Prefabs](./guides/prefabs) - build reusable structures and templates for world editing.
* [Publicando seu mod](./publishing) — Empacote e compartilhe seu mod com os outros usuários.
